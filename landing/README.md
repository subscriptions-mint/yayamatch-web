# YayaMatch landing page

Static marketing page for YayaMatch, deployed as its own Vercel project (root directory `landing/`).
Every "Join now", "For Households", "For Helpers" and "Log in" link opens the app at
https://yayamatch-web-opal.vercel.app. Sign-up happens in the app; this page collects nothing.

Images live in `img/`. `img/phones.webp` is the strip of four redesigned app screens.
